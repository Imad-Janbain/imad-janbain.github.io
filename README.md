# imad-janbain.github.io

Personal portfolio of **Imad Janbain** — Data Scientist & ML Engineer.
Live at **<https://imad-janbain.github.io>**.

Hand-coded single-page site. No frameworks, no trackers, no analytics. Dark and light themes, with the dark theme as the default and a toggle in the nav.

## Design

**Direction:** *Scientific Instrument* — editorial console in lifted slate, with an electric-lime signal accent. Precise monospace labels, a signature instrument-strip visualization (time-series chart with a scan line and a pixel-tile grid representing satellite imagery).

**Palette:** `#181B21` slate · `#EEEDE7` warm cream · `#C6FF3D` electric lime.
**Fonts:** [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) (display), [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) (body), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) (labels).
